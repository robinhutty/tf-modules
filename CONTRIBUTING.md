# Contributing to tf-modules

Thank you for considering contributing to tf-modules!

1. You should be familiar with [git](https://git-scm.com) and github.com.
2. Please discuss major changes in advance.
3. Please test against at least the latest stable version of [OpenTofu][1] and [HashiCorp Terraform][2].

[1]: https://github.com/opentofu/opentofu/releases
[2]: https://github.com/hashicorp/terraform/releases
